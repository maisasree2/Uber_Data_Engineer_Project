# Uber Data Engineering Project

A data engineering project focused on building an end-to-end data pipeline for Uber ride data.

## Tech Stack

* Python
* Apache Spark / PySpark
* Azure Data Lake Storage
* Azure Event Hubs
* Databricks
* SQL

## Project Overview

This project demonstrates data ingestion, processing, transformation, and storage using modern data engineering tools and cloud services.

The pipeline includes streaming data through Azure Event Hubs and processing the data for downstream analytics.

## Project Architecture

The project architecture is included in the repository.

## Project Structure

* `connection.py` — Event Hub connection and data streaming
* `data.py` — Uber ride data generation
* `api.py` — API-related functionality
* `Code_Files/` — Data engineering notebooks and processing scripts
* `Data/` — Sample and reference data
* `templates/` — Application templates

## Note

This is a personal learning project created to practice cloud-based data engineering concepts and build hands-on experience with Azure, Databricks, Python, and Spark.
